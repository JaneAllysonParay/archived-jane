02 / INDIVIDUAL PROJECT

Campus Lost & Found: Making it easier to reconnect people and belongings.

A full-stack campus application to report lost or found items, browse listings, and submit ownership claims—with AI-assisted report review.

Full-stack developmentAPI integrationSoftware testingGemini AI
PROJECT TYPEIndividual project
FRONTENDReact · TypeScript · Vite
BACKENDExpress · MongoDB · Gemini API
01 / THE PROBLEM

A more organized way to look for lost items

Campus lost-and-found reports can be scattered or incomplete. This project explores a clearer user journey: report an item, browse reports, and submit a claim supported by relevant ownership information.

02 / MY ROLE

Built across the stack

I developed the frontend and backend, connected routes and REST APIs to MongoDB, and implemented authentication, protected claim workflows, form validation, and Gemini-powered report review. I used Codex as a development assistant.

01Report

Submit item details using validated forms.

02Browse

03Claim

Provide ownership information.

03 / ARCHITECTURE

From interface to services

The React frontend communicates with an Express API, which manages access to MongoDB through Mongoose and integrates Gemini for report-review assistance.

04 / QUALITY

Testing, iteration, and deployment

The frontend repository documents Vitest tests, linting, production builds, and GitHub Actions CI. I used AI tools for selected development tasks while reviewing the implementation and behavior.

05 / REFLECTION

What the project taught me

Building the complete user journey strengthened my understanding of how frontend decisions, API contracts, data modeling, and reliability shape the user experience.
